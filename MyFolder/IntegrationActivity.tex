\section*{Antiderivatives}

We will now reverse the process of differentiation.  That is, we will be
given a derivative and asked to find the original function. The original function is called
the \textbf{antiderivative} and the process of finding it is called
\textbf{antidifferentiation} or \textbf{integration}.

\begin{theorem}{Definition of an Antiderivative}
A function $F(x)$ is an \textbf{antiderivative} of $f(x)$ if $F'(x)=f(x).$
\end{theorem}

\begin{remark}
Not all functions have antiderivatives, but those that do have infinitely many.  For example, $F(x)=x^2$ is
one antiderivative of $f(x)=2x$ since $F'(x) = f(x).$  However,
$F(x)= x^2+C,$ where $C$ is a constant, is also an antiderivative
of $f(x)=2x,$ thus there are infinitely many antiderivatives of
$f(x)=2x.$

\end{remark}

\subsection*{Notation}

The following notation is used to denote the process of integration and is read as
``the integral of $f(x)$."  The elongated s symbol $\textstyle \int$ is called the \textbf{integral sign} and
the function $f(x)$ is called the \textbf{integrand}.  The differential symbol $dx$
indicates that integration is with respect to the variable $x.$  Together, these symbols are referred to as
an \textbf{indefinite integral}.

\[ \int f(x) \ dx  \hspace{0.4in} \textbf{Indefinite Integral}\]


If $F(x)$ is an antiderivative of $f(x)$ then we can write

\[ \int f(x) \ dx = F(x) + C \]

where $C$ is the \textbf{constant of integration}.

\begin{theorem}[\textbf{Basic Integration Rules}]

You should know the following basic integration rules. The integration formulas for $\tan x$ and $\cot x$ aren’t
listed since they are easily derived by rewriting them in terms of sine and cosine and using a $u$-substitution.

\begin{enumerate}
\item $\displaystyle \int 1 \ dx = x+C $


\item $\displaystyle \int x^n \ dx = \frac{x^{n+1}}{n+1} + C, \hspace{0.3in} n \ne -1 $


\item $\displaystyle \int \frac{1}{x} \ dx = \ln |x| + C $


\item $\displaystyle \int e^x \ dx = e^x + C $


\item $\displaystyle \int \sin x \ dx = - \cos x + C $


\item $\displaystyle \int \cos x \ dx = \sin x + C$


\item $\displaystyle  \int \sec^2 x \ dx = \tan x + C $


\item $\displaystyle \int \csc^2 x \ dx = -\cot x + C $


\item $\displaystyle \int \sec x \tan x \ dx = \sec x + C $


\item $\displaystyle \int \csc x \ \cot x \ dx = -\csc x + C $


\item $\displaystyle \int \frac{1}{\sqrt{a^2-u^2}} \ du =  \arcsin \frac{u}{a} + C, \hspace{0.2in} a > 0 $


\item $\displaystyle \int \frac{1}{a^2 + u^2} \ du =  \frac{1}{a} \arctan \frac{u}{a} + C, \hspace{0.2in} a > 0$

\end{enumerate}
\end{theorem}


\begin{remark}
Often, we must first alter the form of an integrand prior to applying a basic integration rule. If an integrand is not in a
familiar form, try using one of the following techniques to create a familiar form.


\begin{enumerate}
\item Expand a power.

\item Separate a numerator into two or more terms.

\item Use a trigonometric identity.

\item Use a $u$-substitution. Try letting $u$ equal the inner most part of a composite function.

\item Use polynomial division when the degree of the numerator is greater than or equal
to the degree of the denominator.

\item Complete the square.

\item Look for integrands of the form $\textstyle \frac{u'}{u}$ or something close to that. Then let $u$ equal the
denominator. These integrals yield the natural logarithmic function.

\item If an integrand contains a logarithmic function of the form $f(x) = \ln g(x),$ try letting $u = \ln g(x).$ It won’t work in every case, but it often will.

\item Look for integrands with denominators of the form $a^2+u^2$ and $\sqrt{a^2+ u^2}.$ These often result in an answer involving the inverse tangent function or inverse sine function.

\end{enumerate}
\end{remark}

\begin{problem}
Follow the steps below to evaluate the indefinite integral.

\[
\int  3x^2 - \frac{4}{x^3} + \sqrt{x}  \, dx
\]

\begin{enumerate}
\item Rewrite the integrand using standard exponents.

\[
\int 3x^2 - 4x^{\answer{-3}} + x^{\answer{1/2}} \ dx
\]

\item Apply the power rule term-by-term to find the family of antiderivatives.
\[
\int \left( 3x^2 - \frac{4}{x^3} + \sqrt{x} \right) \, dx = x^{\answer{3}} + \frac{\answer{2}}{x^2} + \frac{\answer{2} x^{\answer{3/2}}}{\answer{3}} + C
\]

\end{enumerate}
\end{problem}


\begin{problem}
Evaluate the indefinite integral.

\[
\int \frac{x e^x + 4}{x} \, dx
\]


Split the numerator of the integrand into two separate terms, then integrate term-by-term.  

\[
\int  \answer{e^x} + \frac{\answer{4}}{x} \, dx  = \answer{e^x} + 4\answer{\ln|x|} + C 
\]


\end{problem}


\begin{problem}
Follow the steps below to evaluate the indefinite integral.

\[
\int \frac{\sin x + \cos^3 x }{\cos^2 x} \, dx
\]

\begin{enumerate}
\item First, split the numerator of the integrand into two separate terms,

\[
\int \frac{\sin x}{\cos^2 x} + \answer{\cos x}  \, \answer{dx}
\]

\item The first term can be rewritten as follows.  Simplify this term using standard trigonometric identities.

\[ \frac{\sin x}{\cos x} \cdot \frac{1}{\cos x} = \answer{\tan x} \cdot \answer{\sec x} \]

\item Lastly, rewrite the simplified integral and integrate term-by-term.
\[
\int \answer{\sec x \tan x} + \answer{\cos x} \, \answer{dx} = \answer{\sec x} + \answer{\sin x} + \answer{C}
\]

\end{enumerate}
\end{problem}

\textbf{What happens if we use even more rectangles?}

Our approximation improves as the number of rectangles increases and if we let the number of rectangles approach infinity, we get the exact area.

\begin{definition}[\textbf{Area}]


If $f$ is continuous and nonnegative on $[a,b],$ then the area of the region bounded by
the graph of $f$ and the $x$-axis on $[a,b]$ is given by the following limit.

\[ \textrm{Area} = \lim_{n \rightarrow \infty}  \sum_{i=1}^{n} f(c_i) \Delta x, \]

where $c_i$ is any $x$-value in the $i$th subinterval and $\Delta x = \displaystyle \frac{b-a}{n}.$

\end{definition}

The sum in the above definition is called a \textbf{Riemann sum}, which is a sum used to approximate area.    The limit of the Riemann sum in the above definition is called a \textbf{definite integral} and is denoted as follows.

\[   \lim_{n \rightarrow \infty} \sum_{i=1}^{n} f(c_i) \Delta x = \int_{a}^{b} f(x) \ dx     \]


\begin{remark}
The definite integral is not always interpreted as area.  It depends on the values of $f$ on $[a,b],$ as described below.

\begin{enumerate}
\item If $f(x)$ is \textbf{nonnegative} (positive or 0), the definite integral will give the area of the region bounded by $f$
and the $x$-axis on $[a, b].$

\item If $f$ is \textbf{negative} on $[a, b],$ the definite integral gives the negative of
the area.

\item If $f$ is \textbf{both negative and positive} on $[a, b],$ the definite integral is not interpreted
as area.
\end{enumerate}
\end{remark}

\section*{Definite vs. Indefinite Integrals}

A \textbf{definite integral} is a number whereas an \textbf{indefinite integral} is a family of functions that differ only by a constant, $C.$


\[ \small{\textbf{Definite Integral}} \hspace{0.55in} \normalsize \int_a^b f(x) \ dx = \textrm{Constant} \]

\[ \textbf{Indefinite Integral} \hspace{0.4in}  \int f(x) \ dx = F(x) + C \]


The following theorem establishes the relationship between definite and indefinite integrals.

\begin{theorem}[\textbf{Fundamental Theorem of Calculus}]

~ \\[1em]

If a function $f$ is continuous on $[a,b]$ and $F$ is an antiderivative of $f$ on
$[a,b],$ then

\[ \int_{a}^{b} f(x) \ dx =  F(b)-F(a). \]

\end{theorem}
