\section*{Antiderivatives}

We will now consider how to reverse the process of differentiation.  That is, we will be
given a derivative and asked to find the original function. The original function is called
the \textbf{antiderivative} and the process of finding it is called
\textbf{antidifferentiation} or \textbf{integration}.

\begin{theorem}[\textbf{Definition of an Antiderivative}]

A function $F(x)$ is an \textbf{antiderivative} of $f(x)$ if $F'(x)=f(x).$
\end{theorem}

\begin{remark}
Not all functions have antiderivatives, but those that do have infinitely many.  For example, $F(x)=x^4$ is
one antiderivative of $f(x)=4x^3$ since $F'(x) = f(x).$  However, if $C$ is a constant then $F(x)= x^4+C$ 
is also an antiderivative of $f(x)=4x^3.$  Thus, there are infinitely many antiderivatives of
$f(x)=4x^3.$

\end{remark}



\begin{problem}
Is $F(x) = 3x^2+5$ an antiderivative of $f(x) = 6x?$

\begin{multipleChoice}
\choice[correct]{Yes, $F'(x) = f(x).$}
\choice{No, $F'(x) \ne f(x).$}
\end{multipleChoice}


\end{problem}

\end{problem}


\section*{Notation}

The following notation is used to denote the process of integration and is read as
``the integral of $f(x)$.''  The elongated s symbol: $\textstyle \int$ is called the \textbf{integral sign} and
the function $f(x)$ is called the \textbf{integrand}.  The \textbf{differential} symbol $dx$
indicates that integration is with respect to the variable $x.$  Together, these symbols are referred to as
an \textbf{indefinite integral}.

\[ \int f(x) \ dx  \hspace{0.4in} \textbf{Indefinite Integral}\]


If $F(x)$ is an antiderivative of $f(x)$ then we can write

\[ \int f(x) \ dx = F(x) + C \]

where $C$ is the \textbf{constant of integration}.

\[ \int 5x + 4 \ dx = \frac{x^5}{5} + 4x + C \]

\choice{$\frac{x^5}{5} + 4x + C$}
\choice{$\textstyle \int$}
\end{multipleChoice}

\end{problem}

\begin{theorem}[\textbf{Basic Integration Rules}]

You should know the following basic integration rules. The integration formulas for $\tan x$ and $\cot x$ aren’t
listed since they are easily derived by rewriting them in terms of sine and cosine and using a $u$-substitution.

\begin{enumerate}
\item $\displaystyle \int 1 \ dx = x+C $


\item $\displaystyle \int x^n \ dx = \frac{x^{n+1}}{n+1} + C, \hspace{0.3in} n \ne -1 $


\item $\displaystyle \int \frac{1}{x} \ dx = \ln |x| + C $


\item $\displaystyle \int e^x \ dx = e^x + C $


\item $\displaystyle \int \sin x \ dx = - \cos x + C $


\item $\displaystyle \int \cos x \ dx = \sin x + C$


\item $\displaystyle  \int \sec^2 x \ dx = \tan x + C $


\item $\displaystyle \int \csc^2 x \ dx = -\cot x + C $


\item $\displaystyle \int \sec x \tan x \ dx = \sec x + C $


\item $\displaystyle \int \csc x \ \cot x \ dx = -\csc x + C $


\item $\displaystyle \int \frac{1}{\sqrt{a^2-u^2}} \ du =  \arcsin \frac{u}{a} + C, \hspace{0.2in} a > 0 $


\item $\displaystyle \int \frac{1}{a^2 + u^2} \ du =  \frac{1}{a} \arctan \frac{u}{a} + C, \hspace{0.2in} a > 0$

\end{enumerate}
\end{theorem}


\begin{procedure}[\textbf{Integration Using a u-substitution}]

If $u=g(x)$ then $du=g'(x) \ dx$ and

\[ \int  f(g(x)) \cdot g'(x) \ dx =  \int f(u) \ du =   F(u) + C. \]



\begin{enumerate}
\item Choose a substitution $u=g(x).$

\item Find the derivative of $u$ in differential form: $du=g'(x) \ dx.$

\item Rewrite the integral in terms of the variable $u.$

\item Find the antiderivative with respect to $u.$

\item Write the answer in terms of $x$ by replacing $u$ with
$g(x).$
\end{enumerate}

\end{procedure}


\section*{Integration Tips and Tricks}

Often, we must first rewrite an integrand prior to applying a basic integration rule. If an integrand is not in a
familiar form, try using one of the following techniques to create a familiar form.


\begin{enumerate}
\item Rewrite the integrand using rational exponents.

\item Rewrite the integrand using negative exponents for quantities that appear in the denominator. 

\item Expand a power.

\item Separate a numerator into two or more terms.

\item Use a trigonometric identity.

\item Use a $u$-substitution. Try letting $u$ equal the inner most part of a composite function.

\item Use polynomial division when the degree of the numerator is greater than or equal
to the degree of the denominator.

\item Complete the square.

\item Look for integrands of the form $\textstyle \frac{u'}{u}$ or something close to that. Then let $u$ equal the
denominator. These integrals yield the natural logarithmic function.

\item If an integrand contains a logarithmic function of the form $f(x) = \ln g(x),$ try letting $u = \ln g(x).$ It won’t work in every case, but it often will.

\item Look for integrands with denominators of the form $a^2+u^2$ and $\sqrt{a^2+ u^2}.$ These often result in an answer involving the inverse tangent function or inverse sine function.

\end{enumerate}


\begin{problem}
Follow the steps below to evaluate the indefinite integral.

\[
\int  3x^2 - \frac{4}{x^3} + \sqrt{x}  \, dx
\]

\begin{enumerate}
\item Rewrite the integrand.

\[
\int 3x^2 - 4x^{\answer{-3}} + x^{\answer{1/2}} \ dx
\]

\item Apply the power rule term-by-term to find the family of antiderivatives.
\[
\int \left( 3x^2 - \frac{4}{x^3} + \sqrt{x} \right) \, dx = x^{\answer{3}} + \frac{\answer{2}}{x^2} + 
\frac{\answer{2} \ x^{\answer{3/2}}}{\answer{3}} + C
\]

\end{enumerate}
\end{problem}





\begin{problem}

\end{problem}




\section*{Definite vs. Indefinite Integrals}

A \textbf{definite integral} is a number whereas an \textbf{indefinite integral} is a family of functions that differ only by a constant, $C.$


\[ \textbf{Definite Integral} \hspace{0.55in}  \int_a^b f(x) \ dx = \textrm{Constant} \]

\[ \textbf{Indefinite Integral} \hspace{0.4in}  \int f(x) \ dx = F(x) + C \]


The following theorem establishes the relationship between definite and indefinite integrals.

\begin{theorem}[\textbf{Fundamental Theorem of Calculus}]

If a function $f$ is continuous on $[a,b]$ and $F$ is an antiderivative of $f$ on
$[a,b],$ then

\[ \int_{a}^{b} f(x) \ dx =  F(b)-F(a). \]

\end{theorem}

\begin{remark}
In order to find $F(b)-F(a),$ we must first find the antiderivative, $F(x),$ so the above result is typically written
as follows.

\begin{align*}
\int_{a}^{b} f(x) \ dx & \ = \ F(x) \bigg |_{a}^{b} \\
& \\
& \ = \ F(b)-F(a)
\end{align*}
\end{remark}

\begin{problem}
Evaluate the definite integral using the Fundamental Theorem of Calculus.  Begin by finding the antiderivative.

\begin{align*}
\int_{1}^{4} \left( \frac{3}{\sqrt{x}} - x \right) dx &= \answer{6} x^\answer{1/2} - \frac{x^\answer{2}}{\answer{2}} \bigg |_{1}^{4} \\
                                                      & \\
                                                      &= \answer{-3/2} \\
\end{align*}
\end{problem}


\begin{theorem}[\textbf{\emph{u}-Substitution for Definite Integrals}]

If the function $u=g(x)$ has a continuous derivative on $[a,b]$ and $f$ is continuous on the range of $g,$
then

\[ \int_a^b f(g(x)) \cdot g'(x) \ dx = \int_{g(a)}^{g(b)} f(u) \ du. \]


\textbf{Remarks}

\begin{enumerate}
\item Notice above that the limits of integration have been
changed right after the $u$-substitution.  Usually we wait until the
antiderivative has been found before we decide whether or not to
change the limits of integration.

\item It's not necessary to change the limits of
integration, however there are some Calculus II problems that are much easier to complete if the
limits of integration are changed.  If the limits of
integration are not changed, then the antiderivative must be
rewritten in terms of $x$ before evaluating on the interval
$[a,b].$
\end{enumerate}
\end{theorem}
